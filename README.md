# Squeekchain Terminal Dashboard

Proyek ini adalah alat bantu (CLI Dashboard) untuk komunitas Squeekchain.
Dibuat menggunakan Node.js, Ethers.js, dan Chalk.

## Fitur
- Cek Saldo Sepolia ETH
- Cek Saldo Token SQK
- Cek Gas Price dan Block Number real-time

## Cara Pakai
1. `npm install`
2. `node index.js <ALAMAT_WALLET>`

Dibuat untuk kemajuan ekosistem Squeekchain Genesis.
